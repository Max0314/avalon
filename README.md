# Fribench 阿瓦隆

为朋友聚会制作的中文阿瓦隆：保留原项目的蓝金卡面和圆桌意象，提供在线好友局与离线扫码同桌局。支持 5～10 人、梅林/刺客、派西维尔/莫甘娜/莫德雷德/奥伯伦、湖中仙女、完整任务与刺杀结算。

[打开阿瓦隆](https://avalon.fribench.cn/) · 2026-10-15 已验证部署 `8e06b72`，在线与离线扫码均保留。

## 使用

- 在线：填写昵称 → 创建房间 → 分享邀请链接；朋友加入并准备，房主开局。刷新可恢复当前浏览器的座位。
- 离线：每台设备先联网点“准备离线素材”，随后连接同一 Wi-Fi 或热点。房主创建离线房间，逐人与房主双向扫码，也可复制连接文本。房主刷新后恢复本机牌桌，玩家重新配对恢复原座位。
- 身份：打开身份卡，按住查看，松开遮住；确认后入局。卡面原图里的英文保留，角色说明、操作、规则、记录和错误提示均提供中文。
- 语音：使用外部语音通话或面对面讨论，当前没有内置语音。

在线局由本站服务端主持；离线局由房主设备主持，房主拥有完整本局数据，需要信任房主。离线连接不使用公网 STUN/TURN，访客网络隔离或部分热点可能阻止设备直连。离线不代表设备之间无需网络。

## 本地开发

需要 Node.js 24.11～24.x。

```sh
npm ci
npm run check
npm start
# 打开 http://localhost:3000
npm run test:e2e
node tests/layout.mjs
```

浏览器测试需要 Playwright Chromium：`npx playwright install chromium`。二维码库与扫码库在构建时打包，运行时不依赖 Firebase、外部 CDN 或 Google Fonts。默认数据写到 `data/avalon.sqlite`，不得提交。

## 架构与验证

- `shared/engine.mjs`：共用状态机、权限与逐人信息投影。
- `server/`：原生 HTTP/SSE、SQLite 事务、访客身份、操作去重与重启恢复。
- `web/`：中文界面、在线传输、本机主持 WebRTC、扫码与离线缓存。
- `tests/`：规则/权限/隐私/持久化回归；五人在线完整任务刺杀、五人实际 WebRTC、重连、QR 解码、缓存和移动布局浏览器测试。

分析与取舍见 [上游审计](docs/upstream-audit.md)、[架构及玩法边界](docs/architecture.md)、[部署与回滚](docs/deployment.md)。
