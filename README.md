## 使用

- 在线：填写昵称，创建房间并分享邀请链接，或凭房间码入座。全员就绪后由房主开局。短暂掉线会自动同步原席位和牌桌进度，账号玩家可跨设备恢复本人席位。
- 离线：每台设备先联网点“准备离线素材”，随后连接同一 Wi-Fi 或热点。房主创建离线房间，逐人与房主双向扫码，也可复制连接文本。房主刷新后恢复本机牌桌，玩家重新配对恢复原座位。
- 身份与规则：按住身份卡查看立绘和个人线索，松开遮住。圆桌手册提供玩法、八个角色的图鉴和 5～10 人任务人数及失败门槛。
- 声音：首次点按后播放。顶部音符可选择自动随对局切换或指定三首原创配乐之一，也可分别调节音乐和音效；偏好保存在当前设备。讨论使用外部语音或面对面交流。
- 档案：在线战绩、常玩伙伴、排行榜和本机离线记录均从首页进入。游客认领仍需登录后预览并确认。

在线局由本站服务端主持；离线局由房主设备主持，房主拥有完整本局数据，需要信任房主。离线连接不使用公网 STUN/TURN，访客网络隔离或部分热点可能阻止设备直连。离线不代表设备之间无需网络。

## 本地开发

需要 Node.js 24.11～24.x。

```sh
npm ci
npm run check
npm start
# 打开 http://localhost:3000
npm run test:e2e
node tests/layout.mjs
```

浏览器测试需要 Playwright Chromium：`npx playwright install chromium`。二维码库与扫码库在构建时打包，运行时不依赖 Firebase、外部 CDN 或 Google Fonts。默认数据写到 `data/avalon.sqlite`，不得提交。

## 架构与验证

统一登录与正式 PostgreSQL 接入规范见 [统一登录部署](docs/unified-login.md)。原部署文档与下列 SQLite 说明保留为本地和遗留运行说明，当前正式部署按新规范执行；具体上线提交以运维台账为准。

- `shared/engine.mjs`：共用状态机、权限与逐人信息投影。
- `server/`：原生 HTTP/SSE、持久化事务、访客与账号席位、操作去重和重启恢复。
- `web/`：圆桌界面、手册、阶段反馈、本机音频、在线传输及离线 WebRTC。
- `art/` 与 `audio/`：新立绘、封面和原创配乐，随镜像与离线素材包交付，无外链。配乐可由 `tools/generate-score.py` 原地生成，生成过程需 NumPy 和 FFmpeg。
- `tests/`：规则/权限/隐私/持久化回归；五人在线完整任务刺杀、五人实际 WebRTC、重连、QR 解码、缓存和移动布局浏览器测试。

分析与取舍见 [上游审计](docs/upstream-audit.md)、[架构及玩法边界](docs/architecture.md)、[部署与回滚](docs/deployment.md)。
