# 原创美术源文件

- `camelot.png` 是黄昏湖边城堡的封面原稿。构图保留左侧林雾和右侧浅色石塔，使用森林绿与蜂蜜色。
- `role-atlas.png` 是八个角色的原始立绘。按 4 列 × 2 行等分，顺序为梅林、派西维尔、忠臣、刺客、莫甘娜、莫德雷德、奥伯伦、爪牙。单张输出为 384 × 512 WebP。
- `round-hall.png` 是暮色圆桌厅的空场景原稿。前景留空，石拱、深绿色挂毯和远处烛光为界面和演出的背景。缩放到最大 1440 × 960，编码为 WebP。

源文件随仓库保存，镜像与离线缓存使用对应的 WebP。道具图集的原件和切片说明见 [演出素材目录](../cinematics/source/README.md)。
