# 原创美术源文件

- `camelot.png` 是黄昏湖边城堡的原稿，在好人胜利演出中展现日光下的卡美洛。构图保留左侧林雾和右侧浅色石塔，使用森林绿与蜂蜜色。
- `role-atlas.png` 使用内置 ImageGen 创作。提示词为「雨后石堡，蓝调时刻的真人定装照，八位演员的面部朝向各异，细节可见的湿发、旧羊毛、亚麻和锁子甲，斜侧火把光，4 列 × 2 行满幅排列」。1536 × 1024 原稿按从左至右、从上至下的顺序切出梅林、派西维尔、忠臣、刺客、莫甘娜、莫德雷德、奥伯伦和爪牙。每张 384 × 512，使用 libwebp 质量 87 编码。
- `round-hall.png` 使用内置 ImageGen 创作。提示词为「夜间无人议事的中世纪石厅，坐席视角，黑橡木圆桌占据近景，左侧高窗的蓝色月光照亮木纹，右后方有小炉火，烟灰、潮湿石材和窄幅侧光，电影实景摄影」。1536 × 1024 原稿缩放到 1440 × 960，使用 libwebp 质量 86 编码。

- `council-table.png` 使用内置 ImageGen 创作。提示词要点为「垂直俯拍整张中世纪圆桌，烟熏橡木拼板，磨损的黄铜桌沿，中央低反差罗盘木镶嵌，左侧冷月光与右侧微弱炉火，无椅子、人物或文字」。运行时使用 1120 × 1120 的 WebP，席位和任务标记由界面叠加。

源文件随仓库保存，镜像与离线缓存使用对应的 WebP。道具图集的原件和切片说明见 [演出素材目录](../cinematics/source/README.md)。
