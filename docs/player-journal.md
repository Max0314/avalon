# 圆桌旅人 · 游戏档案

2026-10-19：代码与隔离环境检查完成；生产状态以私有运维仓库的发布回执为准。

登录后默认采用 Fribench 昵称与头像，可一键恢复账号资料，也可以只调整游戏形象；不修改中央账号。游客仍能直接建房/入房并选择同样的 33 张头像。昵称可重复，1～30 个字符；游戏过程中固定展示形象。旧表情头像不再提供选择；原角色卡面不加工、不替换。

首页圆桌旅人面板和房间工具栏提供游戏档案，`/?view=records` 可从账号中心直达。个人档案显示完整场次、获胜、胜率、中止、阵营/角色表现、最近对局、结算角色和任务结果，以及常玩伙伴。仅参与者能看自己的历史，陌生账号不能按对局编号读取；进行中和中止的记录不揭示隐藏角色，个人任务牌不归档。伙伴只基于本人共同完成的在线局，不自动加好友、不公开社交关系。

正式 PostgreSQL 独立保存结果，不关联短期房间的级联删除。开始、结算、命令回执共用权威事务，完成结果只记一次；重复 ACK、回大厅、关房和过期不清除历史。中止不计胜负。排行榜默认不公开，需要本人主动开启；只统计完整、服务器验证、独立真人账号的合格局，胜率榜至少 10 场，同分并列。关闭公开后立即退出。

认领仍为每账号本游戏一次，先预览、明确确认，取消/失败不扣次数。可以同时认领当前游客牌桌和历史，也能在没有活跃房间时认领历史；不会覆盖账号已有牌桌，不把旧游客局变成合格排行局。不能凭已认领的旧游客 Cookie 继续访问。

离线扫码仍采用可信房主主持，33 张头像与卡面一起预缓存。每位参与者只在完成揭晓后保存本机最近 100 场离线结果；仅本机可见，清除浏览器会丢失，不上传、不进入在线排行。没有额外联网要求。

共用模块来自私有运维仓库 `packages/game-kit`，复制版本与源码/头像哈希见 `shared/fribench-game-kit/source.json`，构建自动校验。正式运行仍是原单实例、独立 PostgreSQL、回环 23010；没有新端口/容器。源码恢复必须保留新头像和 SQL 兼容层，不能盲目切回只认 emoji 的旧镜像或回灌数据库覆盖新战绩。
