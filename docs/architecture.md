# 架构、中文规则与数据边界

核对日期：2026-10-15。运行角色与任务人数按 5～10 人经典阿瓦隆实现。所有 UI 操作、规则、角色能力、公共记录、错误提示、安装名称已中文化；原始卡图和文件名保留英文。

在线：浏览器 → 同源 HTTPS → Nginx → Node HTTP/SSE → SQLite。客户端发出带版本及唯一 ID 的命令，服务端在事务中校验/持久化并逐人广播。重试同一 ID 得到回执，过期版本只在同一游戏动作上下文中自动重试。表决全部收齐才公开各人选择，任务仅公开汇总；私人查验只给查验者。

离线：每个玩家分别与房主双向交换压缩 SDP 二维码，通过可靠有序 DataChannel 传送命令和逐人投影；没有 Firebase、信令服务器、STUN 或 TURN。完整房间和重连凭证只存房主浏览器；玩家只保存自己的重连证明。旧连接在重认领时失效。房主可查看本机完整状态，属于模式的信任边界。不能把离线房主宣称为防作弊服务端。房主不能移交本机进程后离席，散场须关闭整桌。

在线访客凭证为 256 位随机值，生产 Cookie 为 `__Host-avalon_sid`，Secure/HttpOnly/SameSite=Lax，不设置 Domain。30 天到期；清理数据或换浏览器不能自动认领原座位。在线房间自最后有效操作起保留 6 小时，服务端重启不会清空。离线本机保存也保留 6 小时。无长期战绩承诺。

角色：梅林不知道莫德雷德；奥伯伦不认识邪恶且不被邪恶认识；派西维尔只看到梅林/莫甘娜候选。好人只能交成功牌。7 人以上第四轮需要两张失败，其余单失败。五次连续否决/三次失败为邪恶胜；三次成功后刺杀梅林。湖中仙女首任为首队长右邻，在第 2、3、4 次任务后且未进入终局时查验，不能查验曾持有者。

离线缓存只含页面、脚本、样式和白名单卡图，不缓存 API、房间快照或 Cookie。首次须各设备联网准备约 30 MB。浏览器可能回收缓存；长期未使用须重新检查。相机只在用户打开扫码时申请，只做本地识别，不请求录音，退出窗口或页面隐藏停止拍摄。

当前无需第三方密钥，不注册中央账号客户端。后续可复用房间、成员/准备、逐人投影、命令回执、SSE、扫码配对、缓存及部署框架；具体游戏状态机独立。统一身份应按中央账号正式契约接入，不能靠跨子域读取 Cookie。

容量边界：单进程同步 SQLite，适合小规模朋友局；没有做并发容量承诺。会话查房间目前遍历近期快照，规模增长时应建立成员索引；限流使用内存，重启会清空计数。生产启用 `TRUST_PROXY=1` 时只能由受控反代访问，Nginx 必须覆盖 `X-Real-IP`，宿主机端口始终回环绑定。
