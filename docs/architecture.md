# 架构、中文规则与数据边界

核对日期：2026-11-18。角色与任务人数按 5～10 人阿瓦隆规则实现。中文角色图鉴从共用规则读取人数、阵营与任务门槛，原始卡图可在角色详情查看。

在线：浏览器 → 同源 HTTPS → Nginx → Node HTTP/SSE → 独立 PostgreSQL。本地开发也可以使用 SQLite。客户端发出带版本及唯一 ID 的命令，服务端在事务中校验和持久化，再逐人广播。实时连接报错或超过 35 秒没有心跳时，客户端按同一席位重新读取牌桌快照并恢复 SSE。操作回执丢失时按原 ID、版本和内容确认，服务端明确返回版本冲突后才按同一动作上下文重试。表决全部收齐才公开各人选择，任务仅公开汇总，私人查验只给查验者。

换桌：邀请码预览只给出房间是否可加入、已用头像和本人所在房间的确认信息。换桌须提交原房间码与当时版本，服务端在同一事务重新验证两桌并写入该次选择的游戏资料。房主确认后关闭原桌，普通玩家可以从大厅或终局离开。目标变满、关闭或原房间变化时保留原座位与资料。大厅房主可提交当前所有席位的完整新顺序，已有准备状态随玩家保留。排序冲突会刷新座次并要求重新拖动。

在线补位：房主可在大厅单个添加机器人、一键补足五席或移除现有机器人。机器人自动准备，保留真人的准备状态，按标准规则使用自身投影出牌。真人房主继续推进任务揭晓。每次补位和行动均使用在线命令的版本校验和持久化，服务重启后从已保存阶段继续。机器人没有登录席位，不能成为房主。该局保留在真人档案，带机器人参加的对局不计公开排行。

头像：新玩家遇到头像冲突时使用本桌空闲头像，重连恢复原头像。已有对局保留此前资料，旧版重复头像仍可改名；大厅手动换头像须选未占用的头像。使用中央资料时若首选头像被占用，保留本桌头像，账号偏好继续供下次入座使用。

离线：每个玩家分别与房主双向交换压缩 SDP 二维码，通过可靠有序 DataChannel 传送命令和逐人投影。配对仅依赖同一局域网。短暂掉线由 WebRTC 尝试恢复，回答码弹窗内显示连接状态并可重新扫码。重扫时出示本浏览器原有的席位凭证。房主浏览器保存完整房间和重连凭证，其他玩家只保存自己的重连证明。重认领后旧连接失效。离线对局信任房主设备，房主可查看本机完整状态。房主散场须关闭整桌。

练习：单页内存中创建 5～10 个席位，其余席位由人机执行规则引擎动作。人机决策只读自身投影和公共信息，真人房主推进任务结果。选定本人身份只影响开局发牌；人机可以暂停和逐项行动。练习局不进入在线或离线档案，也不计排行榜。

在线访客凭证为 256 位随机值，生产 Cookie 为 `__Host-avalon_sid`，Secure/HttpOnly/SameSite=Lax，不设置 Domain，30 天到期。同浏览器访客依靠此凭证恢复座位，统一账号可跨设备恢复本人席位。在线房间和离线本机牌桌自最后有效操作起保留 6 小时。已完成对局的归档规则见[游戏档案](player-journal.md)。

角色：梅林不知道莫德雷德；奥伯伦不认识邪恶且不被邪恶认识；派西维尔只看到梅林/莫甘娜候选。好人只能交成功牌。7 人以上第四轮需要两张失败，其余单失败。五次连续否决/三次失败为邪恶胜；三次成功后刺杀梅林。刺客席位在刺杀阶段仅下发给刺客本人，终局公开身份。湖中仙女首任为首队长右邻，在第 2、3、4 次任务后且未进入终局时查验，不能查验曾持有者。

离线缓存含页面、脚本、样式、原版卡图、头像、立绘、演出道具和音轨。API、房间快照与 Cookie 不进入缓存。首次须各设备联网准备；升级时已准备的设备复用旧卡图与头像，在新缓存补齐后切换。浏览器可能回收缓存。相机只在用户打开扫码时申请，只做本地识别，关闭弹窗或隐藏页面会停止拍摄。

## 界面、阅读与演出

首页、大厅、身份确认、对局与结算使用固定可视区。键盘导致可视区缩小时重新测量，名单、手册和档案在各自区域内滚动，关闭和提交按钮保持可达。恢复和错误提示使用预留位置或盖层。手机和桌面均保留圆桌，桌面旁栏与电视大屏各自布局。

视觉和声音反馈由同一席位前后的权威快照驱动。首个快照与断线追平跳过已发生的演出。先播个人提交回执，后播团队票决和任务揭晓；终局演出可覆盖手册，结束后还原阅读位置。日常阶段提示和手册内的表决入口保留阅读上下文。同桌模式可关掉私密提示声，页面隐藏时停止声音并遮住私密身份及线索。

大屏由玩家在同一浏览器打开，通过房间独占的临时通道同步公开投影。只包含席位展示、组队和已公布结果，角色在结算后才加入。大屏使用独立设备声音设置，来源离开、换桌或关闭时清除。投屏可使用浏览器投射或外接显示器。

中央身份接入复用 Fribench 账号，详见[统一登录与 PostgreSQL](unified-login.md)。业务身份及房间权限仍由阿瓦隆服务端核验。

容量边界：单实例小规模朋友局。会话查房间目前遍历近期快照，限流使用进程内计数。生产启用 `TRUST_PROXY=1` 时只能由受控反代访问，Nginx 必须覆盖 `X-Real-IP`，宿主机端口始终回环绑定。
